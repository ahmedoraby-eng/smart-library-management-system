# 0148. First look: Inter, indigo brand colour, cool neutrals, rounded cards

- **Status:** Superseded by [0020](0020-reading-room-identity.md)
- **Date:** 2026-11-24
- **Area:** visual
- **Deciders:** UX

## Context

The first build needed tokens fast so all screens looked the same.

## Options considered

| Option | For | Against |
|---|---|---|
| **Calm light SaaS look with one indigo brand colour** | fast, AA-checked | looks like many generated UIs |

## Decision

- Inter 400–700 self-hosted, 14 px base, tabular numbers; indigo brand-600 #4F46E5 for primary actions, selection and focus only.
- Tokens: canvas #F7F8FA, type scale 12–28, radius 6–12, card shadow, control height 36 (inputs 40), sidebar 240 px.

## Consequences

- Replaced by Reading Room (ADR 0020); this look survives as the 'Plain' theme.
