# 0128. English only, left to right, light theme

- **Status:** Accepted
- **Date:** 2026-11-24
- **Area:** ux
- **Deciders:** UX

## Context

This is not a client deliverable for an Arabic audience; scope is tight.

## Options considered

| Option | For | Against |
|---|---|---|
| **English LTR, light** | less to build and test | no RTL or dark mode |

## Decision

UI is English only, LTR, light theme only; no RTL and no dark mode.

## Consequences

- The Reading Room and Plain themes are both light (ADR 0020).
